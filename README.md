# Cedar & Steam Cabins (demo)

A fictional three-cabin vacation rental in Lava Hot Springs, Idaho, built as a LavaTech Pro portfolio demo to pitch lodging and Airbnb hosts.

Live: https://martwez.github.io/lodging-demo/

Everything here (business, people, listings, reviews, phone numbers) is fictional. Photos are from Unsplash under the free Unsplash License.

## Stack

Vite, React, TypeScript, Tailwind CSS v4, and Three.js (via `@react-three/fiber`) for the hero animation.

## Develop

```bash
npm install
npm run dev
```

## Deploy

Push to `main`. GitHub Actions builds the site and publishes it to GitHub Pages.
